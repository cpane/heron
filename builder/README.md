# Builder scripts

Scripts for building, setting up and driving a Heron without changing its
code. Each one asks questions as it goes. How to use them:
[`docs/builder-guide.md`](../docs/builder-guide.md).

| Script | What it does |
|---|---|
| `wheel_check.sh <user>@<pi>` | Checks that every wheel turns the right way, and the remote's sticks |
